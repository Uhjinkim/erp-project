## Workforce 상세 흐름

### FN-HR-003 승인형 개인정보 변경 요청

재직 사원이 이메일·급여계좌 변경값을 제출하면 형식과 중복을 검증하고 변경 전 값,
요청값, 요청시각과 함께 `대기` 상태로 기록한다. 실제 인사정보는 아직 변경하지 않는다.

### FN-HR-004 승인·반려

인사관리자는 `대기` 요청만 처리한다. 승인 시 실제 값에 반영하고 반려 시 기존 값을
유지한다. 두 경우 모두 처리 결과·처리자·처리시각을 기록한다.

휴가 신청/승인/회수, 평가 작성/확정의 상세 흐름은 각각의 바운디드 컨텍스트에서 구현한다.

## FN-PY-001 급여 정산 생성

**Actor**: 급여담당자

**진입 조건**: 대상 정산기간이 지정되어 있음

**처리**: 대상 사원과 기간의 급여 정보를 생성하고 기본급·수당·공제를 반영한다.

**종료 조건**: 작성/정산중 상태로 생성된다.

**관련 규칙**: PY-001~PY-003

## FN-PY-001 금액 계산 세부 기준

급여는 기본급·수당·공제 항목을 반영하여 계산한다. 해외 화폐 환산 등으로 원 단위 미만
금액이 발생하는 경우 최종 지급액 산정 시 올림 처리한다.

**관련 규칙**: PY-003, PY-009

## FN-PY-004 급여 확정 취소

**Actor**: 급여담당자

**진입 조건**: 급여가 확정 상태이며 정정 사유가 존재함

**처리**: 확정을 취소하고 사유 및 처리자를 이력에 기록한다.

**종료 조건**: 수정 가능한 작성/정산중 상태가 된다.

**관련 규칙**: PY-005~PY-007
