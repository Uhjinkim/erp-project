## Workforce 상세 흐름

### FN-HR-003 승인형 개인정보 변경 요청

재직 사원이 이메일·급여계좌 변경값을 제출하면 형식과 중복을 검증하고 변경 전 값,
요청값, 요청시각과 함께 `대기` 상태로 기록한다. 실제 인사정보는 아직 변경하지 않는다.

### FN-HR-004 승인·반려

인사관리자는 `대기` 요청만 처리한다. 승인 시 실제 값에 반영하고 반려 시 기존 값을
유지한다. 두 경우 모두 처리 결과·처리자·처리시각을 기록한다.

휴가 신청/승인/회수, 평가 작성/확정, 급여 생성/확정취소의 상세 흐름은 각각의
바운디드 컨텍스트에서 구현한다.

## Board 상세 흐름

### FN-BD-002/FN-BD-007 공지 분류 자동 결정

공지를 작성할 때 시스템은 작성자가 보유한 활성 역할(경영담당자, 인사관리자, 급여담당자)
또는 부서장 여부를 근거로 작성 가능한 업무 분류 집합을 계산한다. 작성자는 이 집합에
속하지 않는 분류를 지정할 수 없다(BD-003, BD-008). 분류는 생성 시점에 고정되며 이후
수정 API로 변경할 수 없다.

### FN-BD-003/FN-BD-004 수정·삭제

작성자 본인 또는 시스템관리자만 처리할 수 있다(BD-006). 삭제는 소프트 삭제로 처리하여
레코드를 보존한다. 삭제된 게시글은 목록·상세 조회에 노출하지 않는다.
