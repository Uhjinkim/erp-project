## FN-LV-001 휴가 신청

- **Actor**: 사원
- **진입 조건**: 로그인한 재직 사원
- **입력**: 휴가 유형, 시작일, 종료일, 필요 시 사유
- **처리**: 잔여일수를 검증하고 승인자를 결정한 뒤 `대기` 상태로 저장한다.
- **종료 조건**: 승인대상자에게 조회 가능한 상태가 된다.
- **관련 규칙**: LV-001~LV-004

## FN-LV-005 휴가 승인·반려

- **Actor**: 부서장 또는 인사관리자
- **진입 조건**: 대상 신청의 승인자로 결정되어 있고 신청 상태가 `대기`
- **처리**: 승인 또는 반려 의사와 필요 시 사유를 기록한다.
- **종료 조건**: 상태가 `승인` 또는 `반려`로 변경된다.
- **관련 규칙**: LV-002~LV-005

## FN-EV-001 소속 사원 평가 작성·수정

- **Actor**: 부서장
- **진입 조건**: 평가 대상자가 자신의 관리 범위에 속하고 평가가 확정되지 않음
- **처리**: 평가 점수와 코멘트를 입력하며 등급은 시스템이 산정한다.
- **종료 조건**: 평가가 작성중 상태로 저장된다.
- **관련 규칙**: EV-001~EV-003

## FN-EV-003 평가 확정

- **Actor**: 인사관리자
- **진입 조건**: 평가 작성이 완료되어 확정 가능한 상태
- **처리**: 평가를 최종 확정 상태로 전환한다.
- **종료 조건**: 사원이 본인의 평가 결과를 조회할 수 있다.
- **관련 규칙**: EV-004, EV-005

## FN-PY-001 급여 정산 생성

- **Actor**: 급여담당자
- **진입 조건**: 대상 정산기간이 지정되어 있음
- **처리**: 대상 사원과 기간의 급여 정보를 생성하고 기본급·수당·공제를 반영한다.
- **종료 조건**: 작성/정산중 상태로 생성된다.
- **관련 규칙**: PY-001~PY-003

## FN-PY-004 급여 확정 취소

- **Actor**: 급여담당자
- **진입 조건**: 급여가 확정 상태이며 정정 사유가 존재함
- **처리**: 확정을 취소하고 사유 및 처리자를 이력에 기록한다.
- **종료 조건**: 수정 가능한 작성/정산중 상태가 된다.
- **관련 규칙**: PY-005~PY-007

## FN-HR-002 내 정보 수정

- **Actor**: 사원
- **진입 조건**: 로그인한 재직 사원이 내 정보 화면에서 `수정` 버튼을 누른 경우
- **입력**: 연락처, 주소, 사내 이메일, 급여계좌(은행·계좌번호) 중 바꿀 항목
- **처리**: 내 정보 화면을 수정 모드로 바꿔 현재 값을 바로 편집하게 한다. 저장해도 인사정보에 즉시 반영하지 않으며,
  `수정완료` 시 바뀐 항목만 FN-HR-003의 개인정보 수정 요청으로 제출한다. 변경이 없으면 제출하지 않는다.
- **종료 조건**: 수정 요청이 `대기` 상태로 생성되거나, 사원이 수정을 취소해 보기 모드로 돌아간다.
- **관련 규칙**: HR-002, HR-003

## FN-HR-003 개인정보 수정 요청 제출

- **Actor**: 사원
- **진입 조건**: 로그인한 재직 사원이 내 정보 수정 모드에서 `수정완료`를 누른 경우
- **입력**: 수정 대상 항목, 수정값
- **처리**: 입력값을 검증하고 요청을 `대기` 상태로 생성한다. 변경 전 값과 요청값, 요청 시각을 이력으로 기록한다.
- **종료 조건**: 인사관리자가 승인·반려할 수 있는 상태가 된다.
- **관련 규칙**: HR-002, HR-003, HR-011, HR-012

## FN-HR-004 개인정보 변경 승인·반려

- **Actor**: 인사관리자
- **진입 조건**: 요청 상태가 `대기`
- **처리**: 승인 시 변경값을 실제 인사정보에 반영하고, 반려 시 기존 값을 유지한다. 처리 결과·처리자·처리 시각을 기록한다.
- **종료 조건**: 요청 상태가 `승인` 또는 `반려`가 된다.
- **관련 규칙**: HR-002, HR-003, HR-011, HR-012

## FN-LV-006 승인 휴가 회수

- **Actor**: 기존 승인권자
- **진입 조건**: 휴가가 `승인` 상태이고 변경 또는 취소 사유가 존재함
- **처리**: 승인 상태를 회수하고 회수 사유·처리자·처리 시각을 기록한다.
- **종료 조건**: 신청자가 내용을 정정할 수 있는 상태가 된다.
- **관련 규칙**: LV-007, LV-008

## FN-LV-007 회수된 휴가 수정·재신청

- **Actor**: 사원
- **진입 조건**: 본인의 승인된 휴가가 회수되어 수정 가능한 상태
- **처리**: 휴가 유형·기간·사유를 정정하고 잔여일수와 승인자를 다시 검증한 뒤 `대기` 상태로 전환한다.
- **종료 조건**: 기존 승인선에 따라 다시 승인·반려할 수 있다.
- **관련 규칙**: LV-001~LV-004, LV-007, LV-008

## FN-EV-001 등급 산정 세부 기준

평가 총점은 100점 만점이다. EV-003의 범위에 따라 `S: 90점 이상`, `A: 80점 이상 90점 미만`,
`B: 70점 이상 80점 미만`, `C: 70점 미만`으로 자동 산정한다. 원문 상세의 정수 구간 표기를
비즈니스 규칙의 경계값 정의로 정리했으며 추가 점수 정책을 만들지 않았다.

## FN-PY-001 금액 계산 세부 기준

급여는 기본급·수당·공제 항목을 반영하여 계산한다. 해외 화폐 환산 등으로 원 단위 미만 금액이 발생하는 경우 최종 지급액 산정 시 올림 처리한다.
- **관련 규칙**: PY-003, PY-009
