## 범위와 Actor

개인·인사정보, 휴가, 게시판, 인사평가, 급여를 포함한다. 사원은 모든 재직자의
기본 신분이며 부서장, 인사관리자, 경영담당자, 급여담당자, 시스템관리자 역할을
독립적으로 복수 보유할 수 있다. 한 역할이 다른 역할의 권한을 자동 부여하지 않으며
퇴사자는 시스템에 접근할 수 없다.

## 주요 상태

- 휴가: `대기 → 승인/반려`, 대기 중 신청자 취소 가능. 승인 정정은
  `승인 → 회수 → 대기 → 승인/반려`로 처리한다.
- 인사평가: `작성중 → 확정`; 부서장이 작성하고 인사관리자가 확정한다.
- 급여: `작성/정산중 → 확정 → 확정취소 → 작성/정산중 → 재확정`; 모든 정정은
  이력으로 남긴다.
