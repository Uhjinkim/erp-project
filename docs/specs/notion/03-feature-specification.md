## Workforce 기능

- `FN-HR-001`: 본인 정보 조회
- `FN-HR-002`: 연락처·주소 직접 변경
- `FN-HR-003`~`FN-HR-005`: 승인형 개인정보 변경 요청, HR 승인·반려, 결과·이력 조회
- `FN-HR-011`: 대기 요청 취소
- `FN-HR-006`~`FN-HR-010`: 사원 등록, 퇴사, 퇴사자 조회, 재입사, 인사이력 등록

## 급여

- **FN-PY-001** 급여 정산 생성 — 급여담당자 — `PY-001`~`PY-003`
- **FN-PY-002** 급여 구성항목 입력·수정 — 급여담당자 — `PY-001`, `PY-003`, `PY-005`
- **FN-PY-003** 급여 확정 — 급여담당자 — `PY-005`, `PY-007`
- **FN-PY-004** 급여 확정 취소 — 급여담당자 — `PY-006`, `PY-007`
- **FN-PY-005** 급여 재확정 — 급여담당자 — `PY-006`, `PY-007`
- **FN-PY-006** 사원별 급여 조회 — 급여담당자 — `PY-008`
- **FN-PY-007** 본인 급여명세 조회 — 사원 — `PY-008`

## 연동 기능

- 휴가 `FN-LV-001`~`FN-LV-008`
- 게시판 `FN-BD-001`~`FN-BD-007`
- 평가 `FN-EV-001`~`FN-EV-004`

기능 구현은 관련 규칙 ID를 테스트와 구현 대응표에서 추적한다.
