## Workforce 기능

- `FN-HR-001`: 본인 정보 조회
- `FN-HR-002`: 연락처·주소 직접 변경
- `FN-HR-003`~`FN-HR-005`: 승인형 개인정보 변경 요청, HR 승인·반려, 결과·이력 조회
- `FN-HR-011`: 대기 요청 취소
- `FN-HR-006`~`FN-HR-010`: 사원 등록, 퇴사, 퇴사자 조회, 재입사, 인사이력 등록

## 연동 기능

- 휴가 `FN-LV-001`~`FN-LV-008`
- 게시판 `FN-BD-001`~`FN-BD-007` (상세는 아래 참고)
- 평가 `FN-EV-001`~`FN-EV-004`
- 급여 `FN-PY-001`~`FN-PY-007`

기능 구현은 관련 규칙 ID를 테스트와 구현 대응표에서 추적한다.

## 게시판 기능

| ID | 기능 | 수행 주체 | 관련 규칙 |
| --- | --- | --- | --- |
| `FN-BD-001` | 일반 게시글 작성 | 사원 | BD-001, BD-002, BD-005 |
| `FN-BD-002` | 공지 작성 | 공지 권한 보유 역할 | BD-003~BD-005 |
| `FN-BD-003` | 게시글 수정 | 작성자, 시스템관리자 | BD-006 |
| `FN-BD-004` | 게시글 삭제 | 작성자, 시스템관리자 | BD-006 |
| `FN-BD-005` | 게시글 목록 조회 | 사원 | BD-007 |
| `FN-BD-006` | 게시글 상세 조회 | 사원 | BD-007 |
| `FN-BD-007` | 급여 공지 작성 | 급여담당자 | BD-003, BD-008 |
