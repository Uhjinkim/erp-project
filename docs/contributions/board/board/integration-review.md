기존 확정 명세에 근거가 있는 내용만 공용 문서에 부분 통합했다.
추가 정책은 승인된 제품 규칙으로 채택하지 않았으며, 기여 초안의 과거 결정·후보는 공용 반영 완료를 뜻하지 않는다.
미반영 항목이 있어 원본 기여 초안은 유지한다. 원본 README.md에는 검토 결과를 덧붙이지 않는다.
