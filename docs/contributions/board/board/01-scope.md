# 기능 범위

- 대상 모듈: `board`
- 작업 브랜치: `board`

## 구현 범위

- 게시글(일반/공지) 작성·수정·삭제·목록·상세 조회
- 게시글 소프트 삭제(`board_posts.deleted_at`)
- 댓글/대댓글(1단계 답글만 허용), 댓글 수정·소프트 삭제
- 게시판 목록 화면: 제목·유형·분류·작성자·작성일만 표시, 클릭 시 상세 화면으로 이동
- 상세 화면: 본문, 댓글·답글, 작성자 본인(또는 시스템관리자)일 때만 수정·삭제 버튼 노출
- 제목/작성자 드롭다운 검색(클라이언트 필터)
- 공지 작성 권한이 없는 사원에게는 게시글 유형·공지 분류 선택창을 숨기고 일반 글쓰기 폼만
  노출

## 제외 범위

- 첨부파일, 조회수
- `board_notice_categories` 시드 데이터 삽입(공유 DB 데이터 쓰기, 별도 승인 필요)
- 프론트엔드 자동화 E2E 테스트
