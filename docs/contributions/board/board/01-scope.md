# 기능 범위

- 대상 모듈: `board`
- 작업 브랜치: `board`

## 구현 범위

- 게시글(일반/공지) 작성·수정·삭제·목록·상세 조회
- 게시글 소프트 삭제(`board_posts.deleted_at`)
- 댓글/대댓글(1단계 답글만 허용), 댓글 수정·소프트 삭제
- 프론트 메뉴 2개(안내서 F5, `features/board/`): "게시판·공지 목록", "게시글 작성". 글 보기는
  목록 화면의 `?postId=` 상태로 열고 메뉴에는 두지 않는다. 상세는
  [07-frontend-screens.md](./07-frontend-screens.md) 참고
- 목록은 구분·제목(댓글 수)·작성자·작성일만 표시하고 제목을 누르면 글 보기로 이동
- 글 보기에서 본인 글(`can_edit`)이면 그 자리에서 수정, `can_delete`면 삭제
- 제목/작성자 드롭다운 검색(클라이언트 필터)
- 게시글 작성에서 공지 작성 권한이 있는 사원에게만 게시글 유형(일반글/공지)·공지 분류 선택칸 노출

## 제외 범위

- 첨부파일, 조회수
- 부서 공지 분류(공지 분류는 경영·인사·급여 세 가지만 사용)
- 프론트엔드 자동화 E2E 테스트
