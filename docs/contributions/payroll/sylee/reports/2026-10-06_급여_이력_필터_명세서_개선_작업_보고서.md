## 1. 요청 사항

1. 이력: 급여담당자만 세부 내용(처리자·사유)을 확인하고, 일반 사원은 상태와 날짜만 본다.
   처리자는 사번이 아니라 이름으로 표시한다. 금액은 천 단위 쉼표를 넣은 정수로만 표시한다.
   수정 이력의 `BASE_PAY=2300000.00` 같은 영문 코드는 급여명세서의 한글 항목명으로 바꾼다.
2. 필터: 상태 기준으로 조회할 수 있게 하고, 확정이 필요한 작성중 건과 아직 작성되지 않은
   대상을 알 수 있게 한다.
3. 급여명세서: 지급 항목에 상여, 공제 항목에 소득세(지방소득세 포함)를 추가한다.
4. 오류: 본인 급여 입력 시도 같은 오류를 상단 경고창으로 알린다.
5. 공용 문서: 급여 작업 중 수정한 공용 문서 내용을 `docs/contributions`로 옮기고 공용 문서는
   작업 전으로 되돌린다. 앞으로 공용 문서는 수정하지 않는다.

## 2. 반영 내용

### 2.1 이력

- 백엔드가 역할에 따라 다른 필드를 내려준다. 급여담당자는 `action`, `changed_at`,
  `actor_employee_no`, `actor_name`, `reason`을, 일반 사원은 `action`, `changed_at`만
  받는다(`PayrollService.can_view_history_details()`, `history_to_summary_dict()`).
  화면에서 숨기는 것만이 아니라 API 응답 자체에서 빠진다.
- 처리자 이름은 workforce 포트(`WorkforceGateway.employee_displays()`)로 조회한다. 이 과정에서
  presentation 계층이 workforce ORM을 직접 조회하던 코드도 포트를 거치도록 정리했다.
- 구성항목 수정 사유는 `기본급 2,300,000원, 국민연금 103,500원`, 확정 사유는
  `차인지급액 2,196,500원 확정` 형식으로 기록한다.
- 화면의 모든 금액은 정수·천 단위 쉼표로 표시하고, 입력값도 정수로 보낸다. 일반 사원의
  이력은 상태와 날짜만, 급여담당자의 이력은 날짜·시각과 처리자 이름·사유를 함께 보여준다.
- 이미 기록된 예전 이력 사유(영문 코드·소수점 형식)는 그대로 남아 있다. 바꾸려면 공유 DB
  데이터 수정이 필요해 승인 전에는 손대지 않았다.

### 2.2 상태 필터

급여 관리 탭의 필터를 부서·사람·정산월·상태 네 가지로 구성했다.

- 상태: 전체 / 작성중(확정 필요) / 확정 / 미작성
- 정산월을 고르면 해당 월의 "작성중 N · 미작성 N · 확정 N" 요약이 표시되고, 누르면 그
  상태로 바로 필터링된다.
- 미작성: 선택한 부서·사람 범위의 재직 사원 중 해당 정산월 급여가 없는 사람을 보여준다.
  "급여 생성"을 누르면 생성 폼에 부서·사람·정산월이 채워진다. 본인은 "본인(생성 불가)"로
  표시한다(최종 차단은 백엔드가 한다).
- 함께 고친 점: 부서만 고르고 사람을 고르지 않으면 이전에는 부서와 상관없이 전체 급여가
  보였는데, 이제 해당 부서 사원으로 좁혀진다. 부서가 없는 사원도 "부서 미지정"으로
  선택할 수 있다.

### 2.3 급여명세서 구성항목

- 소득세(지방소득세 포함)(`INCOME_TAX`, 공제)를 migration
  `payroll/0005_seed_income_tax_component.py`로 추가했다.
- 상여(`BONUS`)는 이전 작업에서 migration `0004`로 만들었지만 공유 DB에 적용되지 않아 화면에
  보이지 않았던 것이다. 사용자 승인 후 0004·0005를 공유 개발 DB에 적용했고(`migrate
  payroll`, 계획 확인 후 실행), 실제 서비스 조회로 활성 구성항목 8건을 확인했다.
- 급여명세서 표는 이제 입력한 항목만이 아니라 활성 구성항목 전체를 참고 양식처럼
  나열한다(금액이 없으면 빈칸). 순서는 기본급·상여·고정수당·초과근무수당 /
  국민연금·건강보험·고용보험·소득세다.

### 2.4 오류 알림

오류는 빨간 경고창(`role="alert"`)으로 화면 상단에 고정되어 표시되고, 화면도 맨 위로
이동한다. 닫기 버튼으로 지울 수 있다. 성공 안내는 기존처럼 일반 알림으로 표시한다.
