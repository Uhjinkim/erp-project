# 급여명세서·이력 표시 개선 작업 보고서

- 작업일: 2026-10-07
- 작업 브랜치: `sylee`
- 작업 범위: 급여 화면 표시 방식(프론트엔드만 변경)

## 1. 요청 사항

1. 급여명세서 조회 시 상여 등 금액이 없거나 0인 항목은 행 자체를 표시하지 않는다.
2. 지급 내역에서 상여를 가장 아래로 옮긴다: 기본급 — 고정수당 — 초과근무수당 — 상여.
3. 이력은 첫 줄에 `상태 / 수정일자 / 담당자`를 표시하고, 줄을 바꿔 나머지 내용을 표시한다.

## 2. 반영 내용

- `PayslipTable`이 활성 구성항목 전체를 나열하던 방식(2026-10-06)을 바꿔, 급여에 실제로
  입력된 항목 중 금액이 0이 아닌 것만 표시한다. 지급·공제 열의 행 수가 다르면 짧은 쪽은
  빈칸으로 채운다. 합계(지급총액·공제액 계·차인지급액)는 그대로 표시한다.
- 표시 순서를 지급 — 기본급·고정수당·초과근무수당·상여, 공제 — 국민연금·건강보험·
  고용보험·소득세로 정했다. 급여 생성·구성항목 편집 폼도 같은 순서다.
- 이력 항목을 두 줄 구조로 바꿨다.
  - 급여담당자: `확정 / 2026. 10. 7. 오후 3:12:00 / 홍길동` 다음 줄에 사유
    (예: `기본급 2,300,000원, 국민연금 103,500원`)
  - 일반 사원: `확정 / 2026. 10. 7.` 한 줄(사유·담당자는 API에서 내려오지 않음)
