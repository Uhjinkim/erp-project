# 급여 대상자 조회 권한 오류 수정·지급일 수정·급여명세서 저장 작업 보고서

- 작업일: 2026-10-12
- 작업 브랜치: `sylee`
- 작업 범위: 급여담당자 권한 오류 수정, 지급일 지정·수정, 확정 급여명세서 PDF·엑셀 저장

## 1. 요청 사항

1. 급여담당자는 본인 급여를 제외하고 모두 급여를 등록할 수 있어야 하는데, "이 작업을
   수행할 권한이 없습니다." 경고가 뜬다.
2. 급여담당자이면서 인사담당자인 사람만 급여를 입력할 수 있는 원인을 찾고, 해결 방안을
   설명한 뒤 진행한다.
3. 지급일을 수정할 수 있게 한다. 현재 자동 지정되는 지급일을 기본으로 하되, 필요하면 바꿀 수
   있게 한다.
4. 직원이 급여 탭에서 확정된 급여명세서를 PDF나 엑셀 파일로 인쇄·저장할 수 있게 한다.

## 2. 원인

`dev`에서 병합된 workforce 변경(PR #5, 커밋 `fe6f584`)이 개인정보 규칙 `HR-001`에 따라
사원 목록 API `GET /api/workforce/employees/`를 인사관리자 전용으로 바꿨다. 급여 화면은
부서→사람 선택 목록을 채우려고 이 API를 호출하고 있었기 때문에, 인사관리자 역할이 없는
급여담당자는 403을 받았다. DRF 기본 메시지가 "이 작업을 수행할 권한이 없습니다."이고,
이 호출이 실패하면 급여 화면 전체 새로고침이 실패해 사람 선택 목록이 비어 급여를 등록할
수 없었다. 인사관리자 역할을 함께 가진 사람만 정상 동작한 이유가 이것이다.

급여 백엔드의 권한 판정(`PAYROLL_MANAGER`) 자체에는 문제가 없었다.

## 3. 해결 방안과 반영

workforce의 권한을 다시 넓히면 `HR-001`이 무력화되고 다른 팀 모듈을 바꾸게 되므로, 급여
모듈 안에 급여 처리에 필요한 최소 정보만 주는 대상자 API를 추가했다.

- `GET /api/payroll/employees/`: 급여담당자만 호출 가능. 사번·이름·부서·직급·재직 여부만
  반환하고 연락처·이메일은 반환하지 않는다.
- workforce 조회는 급여 모듈의 `WorkforceGateway.list_payroll_targets` 포트와
  `DjangoWorkforceGateway` 게이트웨이를 거친다(AGENTS.md의 컨텍스트 간 접근 규칙).
- 급여 화면은 workforce API 대신 이 API로 부서·사람 목록을 만든다. 부서 목록은 대상자의
  부서 정보에서 구성한다.
- 회귀 테스트: 인사관리자가 아닌 급여담당자에게 workforce 사원 목록은 403이고 급여 대상자
  API는 200이며 이메일이 포함되지 않음을 확인한다.

## 4. 지급일 수정

- 급여 생성 폼에 "지급일 (선택)"을 추가했다. 비워 두면 기존처럼 매월 25일(주말·공휴일이면
  직전 평일)로 자동 지정되고, 날짜를 넣으면 그 날짜로 생성된다.
- 기본 지급일을 날짜 칸에 미리 채워 두는 방식(별도 기본 지급일 API)도 만들어 봤으나, 사용자
  결정으로 이 "비워 두면 자동" 방식으로 되돌렸다.
- 작성중 급여의 "지급일·구성항목 편집"에서 현재 지급일을 기본값으로 보여주고 바꿀 수 있다.
  변경은 `수정` 이력에 `지급일 2026-09-25 → 2026-09-24, 기본급 3,000,000원`처럼 남는다.
- 확정된 급여는 지급일을 바꿀 수 없다(`PY-005`). 확정취소 후 수정해야 한다.
- 지급일이 정산월 안이어야 하는지 같은 제한 규칙은 정해진 것이 없어 두지 않았다.

## 5. 급여명세서 PDF·엑셀 저장

- 확정된 급여명세서에 "PDF 저장·인쇄"와 "엑셀 저장" 버튼을 추가했다(내 급여·급여 관리 모두).
- PDF: 브라우저 인쇄 대화상자를 열며, 선택한 명세서만 인쇄되고 버튼·이력은 빠진다.
  대상에서 "PDF로 저장"을 고르면 PDF 파일이 된다. 별도 라이브러리가 필요 없다.
- 엑셀: 백엔드 `GET /api/payroll/statements/{id}/excel/`이 `openpyxl`로 화면과 같은 양식의
  `.xlsx`를 만든다(제목, 성명·직급·사번·지급일, 지급/공제 2단 표, 0원 항목 제외, 합계와
  차인지급액, 원 단위 서식). 본인 또는 급여담당자만 받을 수 있고, 작성중 급여는 400으로
  거절한다.
- 표시 순서(기본급·고정수당·초과근무수당·상여 / 국민연금·건강보험·고용보험·소득세)의 기준을
  백엔드(`PAYSLIP_ORDER`)로 옮겨 화면과 엑셀이 같은 순서를 쓰도록 했다. 프론트엔드에 있던
  같은 순서 목록은 제거했다.
