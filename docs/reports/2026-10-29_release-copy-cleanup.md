# 배포 화면 안내 문구 정리

- 날짜: 2026-10-29, dev
- 요청: 기능 구현 과정에서 추가한 화면 안내 문구 제거.

휴가 신청의 서버 검증·잔여 조회 시점·사용 일수 입력 설명·반차 공유 안내·반복 승인 안내를 제거했다.
잔여 값과 새로고침, 부족 경고, 신청 전 확인 값, 입력 필드·문자 수는 유지한다. 신청 성공 문구는
처리 결과만 표시하고 목록 빈 상태와 승인 확인에서 서버 구현 설명을 제거했다.

사원 조회·등록·역할 화면의 개발 설명을 제거하고 이메일 중복 서버 검사·조직 순환 검사 안내를
정리했다. 재입사 날짜 제약과 퇴사 결과 경고는 유지하되 서버 설명과 내부 규칙 번호는 제거했다.
개인정보의 반복 수정 절차와 계좌 표시 설명, 게시판 권한 필터 설명, 준비 중 화면의 구현 계획을
정리했다. 로그인 아이디 변경, 데이터 삭제/상태 전이 확인, 본인 처리 제한, 입력 제약·오류와
처리 결과 등 실제 판단에 필요한 정보는 유지한다. 코드의 추적 주석과 업무 규칙·권한은 변경하지 않았다.

프론트 lint/build와 62개 테스트 통과. 텍스트/표시만 변경하여 별도 테스트는 추가하지 않았다.
공유 DB/Redis 접근·쓰기와 서버/포트 재시작 없음. 기존 사용자 변경을 보존했다.
