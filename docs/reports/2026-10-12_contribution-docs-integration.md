02·03·04 스냅샷은 2026-10-12 직접 읽은 Notion 원문을 근거로 상세화했다.
BD-004·BD-007의 부서 분류는 사용자 설명과 다른 부분을 정본 정책으로 확대하지 않고 의제로 연결했다.
BD-008은 기존 원문을 유지하며 복수 담당자 선택 정책을 확정하지 않았다.
상태·역할·미확정 정책의 기존 기준은 유지한다. 화면은 이전 디자인 시안을 기준으로 재설계한다.

API 문서는 실제 라우트와 구현 권한을 기록하되, 보류 중인 제한은 제품의 확정 규칙과 구분한다.
테이블 문서는 “모델·마이그레이션 없음”이라는 오래된 설명을 정정하고,
모델 상태·migration 정의와 실제 공유 DB 적용 여부를 분리한다.
충돌 테이블의 신규 설계는 정본 컬럼 명세로 승격하지 않았다.

## 검증

- 원문·현재 라우트·모델·기여 초안 대조 수행.
- Markdown 18개 파일의 상대 링크 60개와 규칙·기능·의제 ID 검사 통과.
- git diff --check 통과. 최종 diff·status 검토에서 문서 변경 범위와 기존 사용자 변경 보존 확인.
- 앞선 검토에서 기존 테스트 5건 통과 및 합성 소수 금액 입력·계산 확인.
- 문서만 변경하여 backend/frontend 전체 테스트·빌드·migration drift 검사는 재실행하지 않았다.
- dev의 승인된 공용 문서 작업이므로 feature 전용 docs-workflow check는 적용하지 않았다.
- 브라우저·현재 공유 DB 적용 상태·공휴일/분류 마스터 데이터는 미검증이다.
- 기존 사용자 변경(.gitignore, 이미지 삭제, scripts/sql)은 보존했다.
