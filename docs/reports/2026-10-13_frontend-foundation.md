# 프론트엔드 공통 토대 구현·검증

- 구현일: 2026-10-13
- 기준 브랜치: dev
- 요청: 모듈 작업 안내서의 토대를 구현하고 dev에 push
- 사용 계약: [공통 토대 사용 계약](../guides/frontend-foundation-contracts.md)

## 변경 결과

Graphite 참고 디자인에 맞춘 토큰·공통 UI·개발용 전시, 앱 셸·hash 기반 화면 등록과 공개 모듈
진입점을 구현했다. 로그인·세션 확인·업무 403과 실제 만료·인증 서버 장애·연결 상태를 앱 계층으로
분리했다. 공용 client는 필드별 오류를 보존하며 기존 세션 쿠키·CSRF 처리를 유지한다.

휴가를 App에서 독립 모듈·API·타입으로 이관하고 공통 폼·탭·카드·상태·사유 입력 Modal을 적용했다.
빈 사유·중복 클릭을 차단하고, 재신청 입력의 일시를 로컬 시간으로 변환한다. 업무 상태 전이와
권한은 기존 서버 계약을 그대로 사용한다. 개발 사원 전환은 화면 트리를 교체해 이전 상태를 제거한다.

개인정보 API·DTO를 workforce와 분리했다. 기존 게시판·사원·평가·급여 패널은 기능을 보존하여
각 모듈의 첫 화면에 연결하고 CSS @scope로 스타일을 격리했다. 기존 급여 인쇄 규칙은 전역
인쇄 스타일로 유지했다. 다른 업무 상세 화면과 홈 집계는 준비 중이며 후속 팀원이 구현한다.

새 라이브러리·환경변수·백엔드 API·스키마를 추가하지 않았다. test 스크립트는 Bun 내장 러너를
사용한다. 앱 토대 사용 문서·배정 안내서 진입 링크·README 검증 명령을 함께 갱신했다.

## 검증 결과

- `bun run test`: 8건 통과. 화면 소유권·라우트/query·유효하지 않은 URL·CSRF·204·필드 오류·
  업무 403 재확인 이벤트와 auth 오류 재귀 방지·서비스 오류 분류.
- `bun run lint`: 오류·경고 없이 통과.
- `bun run build`: strict TypeScript와 Vite production build 통과.
- Air 브라우저에서 개발용 전시 확인: 필드 label·오류 연결, native Modal의 외부 포커스 제한,
  닫기 후 포커스 복귀, 탭 키보드 이동.
- 합성 응답으로 확인: 인증 서버 장애→재시도 복구, 유효 세션에서 업무 403 유지,
  실제 인증 실패→만료 안내·업무 데이터 제거, 재로그인 후 원래 URL 유지.
- 합성 휴가 목록·취소→재조회·빈 상태, 반려 사유의 빈 값 제출 차단과 실행→대화상자 닫기,
  Escape 닫기·포커스 복귀, 모바일 메뉴 펼치기, 등록된 상세 준비 화면→뒤로가기 확인.
- 검증 뷰포트에서 수평 화면 넘침이 없고 제목은 28px로 렌더링됨을 확인.
- 문서 링크·코드 블록·diff 공백 검사 통과. 최종 diff/status를 확인했다.

브라우저 시작 시 로컬 API 프록시의 인증 GET이 502를 반환하여 장애 안내를 확인했다.
그 후 fetch를 합성 응답으로 대체하여 모든 로그인·취소·반려 요청을 브라우저 메모리에서 처리했다.
실제 서버 업무 쓰기, 공유 DB·Redis 접속·migration·seed, Notion 갱신은 수행하지 않았다.
이후 전시를 인증 트리에서 분리하여 전시 직접 열기·새로고침에는 인증/업무 API가 필요하지 않게 했다.

## 남은 검증과 후속 작업

- 실제 세션 서버와 모듈별 API·공유 스키마 연동은 미검증이다. 기존 제품·연동 의제를 해결 완료로
  처리하지 않는다. 새 업무 화면에서 권한·필드·필터·페이지 지원을 재확인한다.
- 기존 패널을 새로운 디자인으로 전부 전환하지 않았다. 개인정보 UI가 기존 사원 패널에도 남아
  있으므로 F2·F3가 분리 PR의 순서를 정한다. 모듈별 최초 화면은 기존 복합 패널의 진입점이다.
- 메뉴 등록은 역할 권한표가 아니다. 실제 정책 확인 후 기능별 메뉴/액션 노출을 구체화한다.
- 모든 브라우저·화면 크기·인쇄/Excel 저장·복수 역할의 실제 서버 회귀를 검증한 것은 아니다.
  CSS @scope와 native dialog 지원 브라우저 기준이며 팀 대상 버전 확인이 필요하다.
- 현재 작업 트리에 있는 별도 휴가 backend 수정·명세·보고서는 이번 커밋에서 제외한다.
- dev 직접 작업이므로 기능 브랜치 기여 초안·문서 scope 검사는 적용하지 않는다.
