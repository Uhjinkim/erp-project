# 모바일·데스크톱 업무 화면 배치 검토와 수정

- 기준: dev 기존 작업 트리. 배포·성능·역할 UX·Lucide 작업을 보존했다.
- 요청: 데스크톱에서 텍스트가 과도하게 벌어지는 문제, 표 헤더와 행 정렬 문제 및 모바일 배치 검토.
- 프론트 표현만 수정했다. API·권한·업무 규칙·스키마·의존성 변경 없음. Notion 조회·수정 없음.

## 재현과 수정

1. 1920px 내 정보 화면에서 본문은 약 1644px, 첫 상세정보 목록은 약 1530px,
   항목명 열은 약 506px였다. AppShell 본문을 최대 1280px로 제한하고 가운데 배치했다.
   상세정보 항목명은 최대 8rem(기본 글꼴 기준 128px)으로 제한하고 값 열만 늘어나게 했다.
   모바일에서는 항목명/값을 위아래로 배치한다. 설명·게시글·평가 의견은 72ch로 읽기 폭을 제한했다.
2. 급여 확정 표의 지급총액/공제총액/차인지급액 헤더는 left, 행은 right였다.
   확정·정산 항목·내 급여명세와 인사 이력의 금액 헤더에 같은 amount 정렬을 지정했다.
   명세 전용 지급액/공제액 헤더도 값과 오른쪽 정렬을 맞췄다. 일반 헤더는 명시적으로 left를
   적용하며 금액 클래스가 우선하도록 선택자 우선순위를 낮게 둔다. 정렬 버튼 추가 여백도 제거했다.
3. 390px 사원 목록/휴가 목록/급여 확정 및 768px 급여 확정에서 페이지 전체가 가로로 넘쳤다.
   공통 Card/필드/탭 래퍼와 업무 grid의 최소 폭을 0으로 만들고 줄어드는 단일 열을 지정했다.
   공통 표는 최소 36rem, 전용 급여명세 표는 28rem로 유지해 좁은 화면에서 영역 안으로 스크롤한다.
4. 추가 확인에서 평가 HR 탭과 급여명세 내부 grid/절대 배치 숨김 라벨이 별도로 넘치는 것을 찾았다.
   탭 래퍼 최소 폭과 1열 트랙을 보정하고, 표 스크롤 래퍼를 숨김 라벨의 위치 기준으로 만들었다.
   body의 고정 최소 폭도 제거해 320px 뷰포트의 세로 스크롤바를 포함한 가용 폭에 맞춘다.
5. 상단 사용자 표시가 길 때 줄바꿈하고 카드 제목·액션도 감싸도록 했다.
   표 스크롤 영역에는 이름·tabIndex를 제공했다. 모바일에서 키보드 오른쪽 화살표로
   급여명세 목록의 scrollLeft가 0→40으로 바뀌는 것을 확인했다.

## 브라우저 검수 방법과 결과

사용자가 실행한 nginx 8080/Vite 5173을 재시작·종료하지 않았다.
임시 HTML/TSX 검수 페이지에서 실제 AppShell/ModuleScreen을 그대로 렌더링하고,
해당 페이지 안의 fetch만 합성 읽기 데이터로 대체했다. 알 수 없는 경로·GET 외 요청은
실제 서버로 전달하지 않고 차단했다. 공유 사원·평가·게시글·급여 데이터는 읽거나 수정하지 않았다.
이 검수는 실제 API/세션/업무 상태 전이 검수와 구분한다.

iframe별 실제 뷰포트 폭을 변경해 CSS media query를 적용했다. 긴 이메일·게시글 제목·평가 의견,
금액·날짜·부서명을 포함했다. 원본 브라우저는 554px 폭이며 iframe은 아래 폭을 사용했다.

| 뷰포트 폭 | 화면 조합 | 수정 후 페이지 가로 넘침·표 정렬 불일치 |
| --- | --- | --- |
| 320px | 17 | 0 |
| 390px | 17 | 0 |
| 768px | 17 | 0 |
| 1024px | 17 | 0 |
| 1440px | 17 | 0 |
| 1920px | 17 | 0 |

화면 17개 × 폭 6개 = 102개 조합이다. 표 렌더링 관찰은 총 66회였고 첫 머리행과 첫 데이터행의
각 열 text-align을 대조했다. 페이지 scrollWidth가 clientWidth+1을 넘는지도 확인했다.
폭 1920px의 내 정보는 수정 후 main 1280px/항목명 128px였다. 넓은 표 자체가 스크롤하는 것은
오류로 세지 않으며 페이지 전체가 넘치지 않는지 구분했다.

화면 범위:
- 내 정보: 내 인사정보, 수정 요청 이력(합성 요청 없음 상태).
- 사원·조직: 사원 목록, 신규 사원 등록, 부서·직급 관리.
- 게시판: 일반게시판 목록, 게시글 작성.
- 휴가: 내 신청 목록, 휴가 신청.
- 인사평가: 팀 평가 대상, HR 관리, 내 확정 평가 결과.
- 급여: 정산 기간, 정산 생성, 정산 항목, 확정·정정, 내 급여명세.

실제 554px 뷰포트에서 모바일 메뉴를 열었을 때 상단→메뉴→본문이 겹침 없이 이어지고,
본문이 메뉴 바로 아래에서 시작하는 것도 확인했다. 검수 종료 후 임시 페이지·소스를 삭제하고
브라우저를 원래 앱으로 돌렸다. 검수 fixture·임시 진입점은 배포 코드에 남기지 않았다.
